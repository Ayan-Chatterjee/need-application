# Enterprise Solutions - Web Development Platform

Yeah, it's another React landing page. But *this one's different* (they all say that).

## 🚀 Quick Start (AKA "Please Don't Break It")

### Prerequisites
- Node.js 18+ (because apparently 16 is ancient now)
- npm or yarn (pick your poison)

### Installation

```bash
# Install dependencies (this'll take a while, grab coffee)
npm install --legacy-peer-deps

# Start development server (pray it works first try)
npm run dev

# Build for production (because dev obviously isn't good enough)
npm run build

# Preview production build (see what you actually built)
npm run preview
```

The app will be available at `http://localhost:5173` (unless you're already using that port, then good luck).
